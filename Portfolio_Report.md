# Personal Portfolio Website – Brief Report

## 1. Introduction
This project presents a responsive personal portfolio website developed for the Personality Skills & Development (PSD 4) assignment. The website represents Ramanayakage Hansi Bhagya Senevirathna, a third-year BSc (Hons) in Business Information Systems undergraduate at the University of Sri Jayewardenepura and an aspiring IT Auditor.

## 2. Design Approach
The portfolio uses a clean, modern and professional visual style. A simple navigation bar allows users to move between Home, About, Skills, Projects and Contact sections. The Home section provides a short professional introduction, profile photograph and career objective. The About section presents educational background and qualifications, while the Skills section organizes technical, analytical, tool-based and professional capabilities into clear cards.

The Projects section presents academic work in a consistent card-based layout. Two completed projects are currently included: Parking Space Rental System Website and Statistical Calculator. A third project placeholder has been included and can be replaced when the project details are available.

## 3. Technologies Used
- HTML5 – page structure and semantic content
- CSS3 – layout, typography, responsive design and visual styling
- JavaScript – mobile navigation and contact-form interaction
- Google Fonts – typography
- Git/GitHub – source-code/version-control support
- Responsive CSS media queries – desktop and mobile compatibility

## 4. Responsiveness and Accessibility
The website uses a responsive layout with CSS media queries so content adapts to smaller screens. Navigation changes to a mobile menu, project and skill cards stack vertically, and the profile image scales according to screen size. Images include alternative text and form controls use labels to improve usability.

## 5. Conclusion
The completed portfolio provides a professional online representation of the student's academic background, skills, projects and career direction. It is structured so that additional projects, achievements and professional information can be added later without changing the overall design.
